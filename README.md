# Population Data Visualization

This project analyzes population growth for selected countries using Python and pandas.

## 📊 Features
- Data cleaning and preprocessing
- Pivot table creation
- Multiple visualizations:
  - Line plot
  - Bar charts
  - Pie chart
  - Histogram
  - Scatter plot

## 📁 Files
- `population_analysis.ipynb` → main analysis notebook
- `population_total.csv` → dataset
- `pivot_table.xlsx` → processed data
- `population_plot.png` → saved visualization

## 🛠️ Technologies
- Python
- pandas
- matplotlib

## 📈 Goal
To explore population trends and practice data visualization techniques.
